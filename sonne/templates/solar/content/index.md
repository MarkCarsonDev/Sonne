# Welcome to Solar

This is a demonstration of the Sonne Solar template - a minimalist, energy-efficient website template designed to minimize resource usage and environmental impact.

## Energy Efficiency Features

- **Dark Mode by Default**: Reduces power consumption on OLED screens
- **Minimal JavaScript**: Limited scripting reduces CPU usage
- **Image Dithering**: Smaller file sizes and artistic effect
- **Reduced Animations**: Optional animations to save power
- **WebP Images**: Smaller file sizes for faster loading
- **Inline Critical CSS**: Faster rendering with minimal requests
- **Low Contrast Option**: Less power-intensive on displays

## Current Power Status

This site displays the current battery status of the server. When available, the site runs on solar power during daylight hours, switching to battery power at night.

## Weather Integration

The site integrates with a weather API to display current conditions and forecast for Long Beach, CA. This demonstrates how external data can be incorporated while maintaining energy efficiency.

## Content Features

The Solar template supports all standard Sonne features:

- **Blog system** with tags and categories
- **Portfolio showcase** for projects
- **Markdown content** for easy editing
- **Responsive design** for all devices
- **Image optimization** for bandwidth savings

## Try It Yourself

To experience the full benefits of this template:

1. Toggle between dark and light modes
2. View the page on both mobile and desktop
3. Check out the blog and project sections
4. Monitor your device's energy usage

This template is ideal for environmentally-conscious websites, solar-powered servers, or any project where energy efficiency is a priority.

### Carbon Impact

Websites contribute to carbon emissions through server energy use, network traffic, and client-side rendering. The Solar template reduces this impact by:

- Minimizing data transfer
- Reducing CPU usage
- Optimizing for lower power consumption

By adopting energy-efficient web design principles, we can collectively reduce the environmental impact of the internet.
