# Welcome to My Blog

This is a blog site created with Sonne Static Site Generator. You can edit this page by modifying the `content/index.md` file.

## Recent Posts

Check out my [latest blog posts](/blog/) or read more [about me](/about/).

## Features

- Clean blog layout with focus on readability
- Tag-based organization of content
- Responsive design for all devices
- RSS feed for subscribers

## Getting Started

Edit the `content/index.md` file to change this page, or add new Markdown files to the `content` directory to create additional pages.

To write blog posts, add Markdown files to the `content/blog` directory with the naming convention `YYYY-MM-DD-title.md`.
