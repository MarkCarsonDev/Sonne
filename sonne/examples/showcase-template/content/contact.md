## Frequently Asked Questions

Before contacting us, you might find answers to common questions in our FAQ:

<div class="faq-section">
    <div class="faq-item">
        <h3>How do I install Sonne?</h3>
        <div class="faq-answer">
            <p>Sonne can be installed with pip:</p>
            <pre><code>pip install sonne</code></pre>
            <p>For more detailed installation instructions, check out our <a href="/docs/installation/">installation guide</a>.</p>
        </div>
    </div>
    
    <div class="faq-item">
        <h3>What are the system requirements for Sonne?</h3>
        <div class="faq-answer">
            <p>Sonne requires Python 3.8 or later. It works on Windows, macOS, and Linux.</p>
        </div>
    </div>
    
    <div class="faq-item">
        <h3>Is Sonne free to use?</h3>
        <div class="faq-answer">
            <p>Yes, Sonne is open-source software released under the MIT License, which allows for free use in both personal and commercial projects.</p>
        </div>
    </div>
    
    <div class="faq-item">
        <h3>How do I create a new site with Sonne?</h3>
        <div class="faq-answer">
            <p>You can create a new site using the <code>sonne new</code> command:</p>
            <pre><code>sonne new -p my-site -t blog</code></pre>
            <p>This creates a new site in the "my-site" directory using the blog template.</p>
        </div>
    </div>
    
    <div class="faq-item">
        <h3>Where can I find documentation?</h3>
        <div class="faq-answer">
            <p>Comprehensive documentation is available on our <a href="/docs/">documentation page</a>. You can also find examples and tutorials in our <a href="/blog/">blog</a>.</p>
        </div>
    </div>
    
    <div class="faq-item">
        <h3>How do I report a bug?</h3>
        <div class="faq-answer">
            <p>Bugs can be reported on our <a href="https://github.com/MarkCarsonDev/Sonne/issues">GitHub issues page</a>. Please include as much detail as possible, including your Sonne version, operating system, and steps to reproduce the issue.</p>
        </div>
    </div>
</div>
