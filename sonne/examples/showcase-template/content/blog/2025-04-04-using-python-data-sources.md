# Using Python Data Sources in Sonne

One of Sonne's most powerful features is its ability to use Python scripts as data sources for your static site. This allows you to generate dynamic content at build time, pulling from databases, APIs, or performing calculations that would be impossible with traditional static site generators.

## Why Use Python Data Sources?

Before diving into implementation, let's understand why Python data sources are useful:

1. **Dynamic Content**: Generate content based on calculations or algorithms
2. **External Data**: Pull in data from APIs, databases, or other external sources
3. **Content Aggregation**: Collect and process data from multiple sources
4. **Custom Processing**: Perform specialized data transformations
5. **Automation**: Automate content generation based on patterns or rules

## Setting Up Python Data Sources

In Sonne, Python data sources are scripts placed in the `scripts` directory. These scripts are executed during the build process, and their output is made available to your templates.

### Basic Structure

Here's the basic structure of a Python data source script:

```python
"""
Example data source for Sonne.
This script generates data that can be used in templates.
"""

# The sonne_var function will be injected by Sonne at runtime
def sonne_var(key, value):
    """Set a global variable in Sonne."""
    pass

# Generate some data
data = {
    "title": "Generated by Python",
    "items": ["Item 1", "Item 2", "Item 3"],
    "count": 42
}

# Make it available as a global variable
sonne_var("example_data", data)
```

When Sonne builds your site, it runs this script and makes the `example_data` variable available to all your templates:

```html
<div class="python-data">
    <h2>{{ example_data.title }}</h2>
    <p>There are {{ example_data.count }} items:</p>
    <ul>
        {% for item in example_data.items %}
        <li>{{ item }}</li>
        {% endfor %}
    </ul>
</div>
```

Generate statistics about your site:

```python
import os
from pathlib import Path
from datetime import datetime

    pass

def count_files(directory, extensions=None):
    """Count files in a directory, optionally filtering by extension."""
    count = 0
    for path in Path(directory).rglob('*'):
        if path.is_file():
            if extensions is None or path.suffix.lower() in extensions:
                count += 1
    return count

content_dir = os.path.join(os.getcwd(), 'content')
stats = {
```

### Example 3: Data Processing

Process and analyze data:

```python
import os
import csv
import statistics
from collections import Counter

def sonne_var(key, value):
    pass

# Path to CSV data file
data_file = os.path.join(os.getcwd(), 'data', 'site_stats.csv')

try:
    if os.path.exists(data_file):
        with open(data_file, 'r', encoding='utf-8') as f:
            reader = csv.DictReader(f)
            data = list(reader)
            
            # Convert string values to numbers where appropriate
            for row in data:
                for key in ['page_views', 'unique_visitors']:
                    row[key] = int(row[key])
                for key in ['bounce_rate', 'avg_time_on_site']:
                    row[key] = float(row[key])
            
            # Calculate statistics
            total_views = sum(row['page_views'] for row in data)
            total_visitors = sum(row['unique_visitors'] for row in data)
            avg_bounce_rate = statistics.mean(row['bounce_rate'] for row in data)
            avg_time = statistics.mean(row['avg_time_on_site'] for row in data)
            
            # Month with most traffic
            max_traffic_month = max(data, key=lambda x: x['page_views'])['month']
            
            # Prepare summary
            summary = {
                "total_views": total_views,
                "total_visitors": total_visitors,
                "avg_bounce_rate": round(avg_bounce_rate, 1),
                "avg_time": round(avg_time, 1),
                "max_traffic_month": max_traffic_month,
                "data": data  # Include full data set
            }
            
            sonne_var("analytics_summary", summary)
        
except Exception as e:
    sonne_var("analytics_error", f"Error processing analytics data: {str(e)}")
```

### Working with Databases

Connect to databases for content extraction:

```python
import sqlite3
import json
from pathlib import Path

def sonne_var(key, value):
    pass

# Connect to SQLite database
db_path = Path(__file__).parent.parent / "data" / "content.db"

try:
    conn = sqlite3.connect(str(db_path))
    conn.row_factory = sqlite3.Row  # This enables column access by name
    
    # Query products
    cursor = conn.cursor()
    cursor.execute("""
        SELECT id, name, description, price, category, image_url 
        FROM products 
        WHERE active = 1
        ORDER BY category, name
    """)
    
    # Convert to list of dictionaries
    products = []
    for row in cursor.fetchall():
        product = {key: row[key] for key in row.keys()}
        products.append(product)
    
    # Group by category
    categories = {}
    for product in products:
        cat = product["category"]
        if cat not in categories:
            categories[cat] = []
        categories[cat].append(product)
    
    # Make data available to templates
    sonne_var("products", products)
    sonne_var("product_categories", categories)
    
    conn.close()
    
except Exception as e:
    sonne_var("db_error", f"Database error: {str(e)}")
```

### Generating Navigation Structures

Create complex navigation structures programmatically:

```python
import os
from pathlib import Path
import yaml
import re

def sonne_var(key, value):
    pass

def extract_front_matter(file_path):
    """Extract front matter from a markdown file."""
    with open(file_path, 'r', encoding='utf-8') as f:
        content = f.read()
    
    # Look for YAML front matter
    match = re.match(r'^---\s*\n(.*?)\n---\s*\n', content, re.DOTALL)
    if match:
        try:
            front_matter = yaml.safe_load(match.group(1))
            return front_matter
        except Exception:
            return {}
    return {}

def generate_site_map():
    """Generate a site map from the content directory."""
    content_dir = os.path.join(os.getcwd(), 'content')
    site_map = []
    
    # Process root level pages first
    root_pages = []
    for file_path in Path(content_dir).glob('*.md'):
        # Skip files that start with underscore (drafts or partials)
        if file_path.name.startswith('_'):
            continue
            
        # Get front matter
        front_matter = extract_front_matter(file_path)
        
        # Calculate URL
        if file_path.stem == 'index':
            url = '/'
        else:
            url = f'/{file_path.stem}/'
            
        # Extract title and other metadata
        title = front_matter.get('title', file_path.stem.replace('-', ' ').title())
        nav_order = front_matter.get('nav_order', 999)
        nav_title = front_matter.get('nav_title', title)
        
        # Add to site map
        root_pages.append({
            'title': title,
            'nav_title': nav_title,
            'url': url,
            'order': nav_order
        })
    
    # Sort root pages by order
    root_pages.sort(key=lambda x: x['order'])
    site_map = root_pages
    
    # Process sections
    sections = {}
    for dir_path in Path(content_dir).glob('*/'):
        # Skip special directories
        if dir_path.name in ['blog', '_drafts', '_includes']:
            continue
            
        section_name = dir_path.name
        section_index = dir_path / 'index.md'
        
        if section_index.exists():
            index_data = extract_front_matter(section_index)
            section_title = index_data.get('title', section_name.replace('-', ' ').title())
            section_order = index_data.get('nav_order', 999)
        else:
            section_title = section_name.replace('-', ' ').title()
            section_order = 999
            
        # Get pages in this section
        section_pages = []
        for file_path in dir_path.glob('*.md'):
            if file_path.name == 'index.md' or file_path.name.startswith('_'):
                continue
                
            front_matter = extract_front_matter(file_path)
            
            # Calculate URL
            url = f'/{section_name}/{file_path.stem}/'
                
            # Extract title and other metadata
            title = front_matter.get('title', file_path.stem.replace('-', ' ').title())
            nav_order = front_matter.get('nav_order', 999)
            nav_title = front_matter.get('nav_title', title)
            
            # Add to section pages
            section_pages.append({
                'title': title,
                'nav_title': nav_title,
                'url': url,
                'order': nav_order
            })
            
        # Sort section pages by order
        section_pages.sort(key=lambda x: x['order'])
        
        # Add section to site map
        site_map.append({
            'title': section_title,
            'nav_title': section_title,
            'url': f'/{section_name}/',
            'order': section_order,
            'children': section_pages
        })
    
    # Sort site map by order
    site_map.sort(key=lambda x: x['order'])
    
    return site_map

# Generate site map
site_map = generate_site_map()
sonne_var("site_map", site_map)
```

Use in templates:

```html
<nav class="main-nav">
    <ul>
        {% for item in site_map %}
        <li class="{% if item.children %}has-children{% endif %}">
            <a href="{{ item.url }}" {% if page.url == item.url %}class="active"{% endif %}>
                {{ item.nav_title }}
            </a>
            
            {% if item.children %}
            <ul class="submenu">
                {% for child in item.children %}
                <li>

                    </a>

</nav>
```

## Best Practices

When working with Python data sources in Sonne, keep these best practices in mind:

### 1. Handle Errors Gracefully

Always wrap your code in try-except blocks to prevent build failures:

```python
try:
    # Your code here
    sonne_var("my_data", data)
except Exception as e:
    sonne_var("my_data_error", str(e))
    print(f"Error in data source: {e}")
```

### 2. Cache External Data

For APIs or slow data sources, implement caching:

```python
import os
import json
import time

def sonne_var(key, value):
    pass

def fetch_with_cache(url, cache_file, cache_duration=3600):
    """Fetch data with caching.
    
    Args:
        url: The URL to fetch data from
        cache_file: Path to the cache file
        cache_duration: Cache duration in seconds (default: 1 hour)
    """
    # Check if cache exists and is fresh
    if os.path.exists(cache_file):
        file_age = time.time() - os.path.getmtime(cache_file)
        if file_age < cache_duration:
            # Cache is fresh, use it
            with open(cache_file, 'r', encoding='utf-8') as f:
                return json.load(f)
    
    # Cache doesn't exist or is stale, fetch new data
    import requests
    response = requests.get(url)
    response.raise_for_status()
    data = response.json()
    
    # Save to cache
    os.makedirs(os.path.dirname(cache_file), exist_ok=True)
    with open(cache_file, 'w', encoding='utf-8') as f:
        json.dump(data, f)
    
    return data

# Example usage
cache_dir = os.path.join(os.getcwd(), '.cache', 'data_sources')
cache_file = os.path.join(cache_dir, 'api_data.json')

try:
    data = fetch_with_cache(
        'https://api.example.com/data',
        cache_file,
        cache_duration=86400  # 24 hours
    )
    sonne_var("api_data", data)
except Exception as e:
    sonne_var("api_error", str(e))
```

### 5. Be Mindful of Build Performance

Long-running scripts can slow down your build process:

```python
# Bad - slow script with no feedback
def slow_process():
    import time
    for i in range(1000):
        # Complex processing
        time.sleep(0.01)
    return "Done"

# Better - progress reporting
def better_process():
    import time
    results = []
    total = 1000
    
    print(f"Processing {total} items...")
    
    for i in range(total):
        # Complex processing
        results.append(i)
        
        # Report progress every 10%
        if i % (total // 10) == 0:
            print(f"Progress: {i / total * 100:.0f}%")
            
        # Simulate work
        time.sleep(0.001)
        
    print("Processing complete!")
    return results
```

## Debugging Python Data Sources

When your Python data source isn't working as expected, follow these debugging steps:

1. **Print Statements**: Add print statements to track execution flow:

```python
print(f"Loading data from: {file_path}")
print(f"Processed {len(data)} items")
print(f"Final result: {result}")
```

2. **Dump State**: Save intermediate state to a file:

```python
import json

# Dump intermediate state to a file
def dump_state(name, data):
    with open(f"debug_{name}.json", 'w', encoding='utf-8') as f:
        json.dump(data, f, indent=2, default=str)

# Use in your code
dump_state("after_processing", processed_data)
```

3. **Validate Output**: Ensure the data you're generating is as expected:

```python
def validate_data(data, schema):
    """Validate data against a simple schema."""
    for key, expected_type in schema.items():
        if key not in data:
            print(f"ERROR: Missing required key: {key}")
        elif not isinstance(data[key], expected_type):
            print(f"ERROR: Key {key} has wrong type. Expected {expected_type}, got {type(data[key])}")

# Example usage
projects_schema = {
    "title": str,
    "url": str,
    "description": str,
    "date": str
}

for project in projects:
    validate_data(project, projects_schema)
```

## Conclusion

Python data sources are a powerful feature of Sonne that extends what's possible with a static site generator. By leveraging the full capabilities of Python, you can create rich, dynamic content that's still delivered as static HTML.

Whether you're pulling in data from external APIs, processing complex datasets, or generating content programmatically, Python data sources give you the flexibility to create sophisticated websites without the complexity of a dynamic backend.

Remember that although the data is generated dynamically at build time, the final output is still static HTML, CSS, and JavaScript. This gives you the best of both worlds: the flexibility of dynamic content generation with the performance and security benefits of static sites.
