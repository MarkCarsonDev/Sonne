Discover a collection of websites built with Sonne. These projects showcase the versatility and capabilities of the Sonne Static Site Generator.

## Featured Projects

Sonne powers a wide range of websites, from personal blogs to business sites and portfolios. Below are some examples of what can be achieved with Sonne.

Each project featured here takes advantage of different Sonne features:

- **Responsive images** with automatic optimization

- **Python data sources** for dynamic content

## Get Started

Ready to build your own site with Sonne? Check out our [getting started guide](/blog/2025/04/01/getting-started-with-sonne-static-site-generator/) or install Sonne right away:

```bash
pip install sonne
sonne new -p my-site -t blog
cd my-site
sonne serve
```
